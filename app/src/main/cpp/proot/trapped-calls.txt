# The system calls Android's app policy traps at some API level from 30 to 36,
# one per line as "ABI NAME MARK", and how P4's handle_seccomp_event_common
# answers each at its SIGSYS stop:
#
#   translated  P4 turns it into a call the policy allows, or answers it
#   upstream    proot's own translation or answer
#   ENOSYS      the default
#   EPERM       a call bionic's blocklist names, as its callers expect
#
# The -0, --sysvipc and ashmem_memfd extensions answer their calls first.
# tests/trapped-calls.py regenerates the list from bionic-seccomp/ and fails
# when a trapped call is missing here.
